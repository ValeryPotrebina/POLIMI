## 3. Schwarz Iteration Flow

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      SCHWARZ ITERATION FLOWCHART                             │
└─────────────────────────────────────────────────────────────────────────────┘

                              ┌─────────────┐
                              │    START    │
                              └──────┬──────┘
                                     │
                                     ▼
                         ┌───────────────────────┐
                         │  Initialize u⁽⁰⁾ = 0  │
                         │  Set k = 0            │
                         └───────────┬───────────┘
                                     │
         ┌───────────────────────────┼───────────────────────────┐
         │                           │                           │
         ▼                           ▼                           ▼
┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
│   Subdomain 1   │       │   Subdomain 2   │       │   Subdomain N   │
│                 │       │                 │       │                 │
│ Get BC from     │       │ Get BC from     │       │ Get BC from     │
│ neighbors (k-1) │       │ neighbors (k-1) │       │ neighbors (k-1) │
│                 │       │                 │       │                 │
│ Solve local     │       │ Solve local     │       │ Solve local     │
│ problem         │       │ problem         │       │ problem         │
│                 │       │                 │       │                 │
│ u₁⁽ᵏ⁾           │       │ u₂⁽ᵏ⁾           │       │ uₙ⁽ᵏ⁾           │
└────────┬────────┘       └────────┬────────┘       └────────┬────────┘
         │                         │                         │
         │      PARALLEL           │                         │
         │      (MPI/OpenMP)       │                         │
         │                         │                         │
         └─────────────────────────┼─────────────────────────┘
                                   │
                                   ▼
                      ┌────────────────────────┐
                      │  Exchange Boundaries   │
                      │  (MPI_Send/Recv or     │
                      │   shared memory)       │
                      └───────────┬────────────┘
                                  │
                                  ▼
                      ┌────────────────────────┐
                      │  Compute Residual      │
                      │  r = max‖u⁽ᵏ⁾-u⁽ᵏ⁻¹⁾‖  │
                      └───────────┬────────────┘
                                  │
                                  ▼
                          ┌──────────────┐
                          │   r < ε ?    │
                          └──────┬───────┘
                                 │
                    ┌────────────┴────────────┐
                    │ NO                      │ YES
                    ▼                         ▼
           ┌────────────────┐       ┌────────────────────┐
           │  k = k + 1     │       │ Assemble Solution  │
           │                │       │ u = Σ Pᵢuᵢ⁽ᵏ⁾      │
           │  k < max_iter? │       └─────────┬──────────┘
           └───────┬────────┘                 │
                   │                          ▼
          ┌────────┴────────┐           ┌──────────┐
          │ YES         NO  │           │   END    │
          ▼                 ▼           └──────────┘
    (back to loop)    ┌──────────┐
                      │ FAILED   │
                      │ (no conv)│
                      └──────────┘
```
